# AAExpenseSplitter（AA记账）

一款离线优先的记账 App（基础体验对标钱迹），后续将加入 AA 共享账本：标记为 AA（两人平分）的支出可加密同步到伙伴的账本并一键结算。设计文档见 [Docs/AA记账-功能设计框架.md](Docs/AA记账-功能设计框架.md)。

## 当前状态：M2（AA 共享 · 无服务器文件同步）

**M1 本地记账（已完成）：**

- ✅ 记一笔：支出 / 收入 / 转账，数字键盘 + 12 个预置分类 + 账户选择 + 日期 + 备注，「再记」连续记账
- ✅ 明细页：按月切换、按日分组带日小计、月收支结余摘要、点击编辑/删除（软删除）
- ✅ 图表页：本月分类支出饼图 + 排行、近 6 个月收支趋势柱状图
- ✅ 账本：总资产卡片、账户增改删（预置现金/微信/支付宝/银行卡）、余额自动累计

**M2 AA 共享（已完成，无服务器方案）：**

- ✅ 配对：双方约定同一「配对口令」，各自在本机完成配对，自动创建「AA挂账」虚拟账户
- ✅ AA 记账：支出页新增「AA · 与伙伴平分」开关；垫付方记全额 + 自动生成挂账应收（伙伴份额，不计收支）
- ✅ 加密文件同步：导出 `.aas` 文件（口令 PBKDF2 → AES-256-GCM 端到端加密），微信/QQ 发给对方导入；仅同步 AA 数据，普通账单永不外传
- ✅ 接收方待入账：导入后不静默建账，进「待你入账」队列，由接收方选账户/分类/备注后「入账并确认」；也可直接「退回」（**可附理由**）
- ✅ 差额与结算：差额卡片实时显示「谁欠谁多少」，**退回挂起/已取消的账单不计入差额**；一键结算核销全部可结算 AA 账单（挂起单不吞），双方账本自动生成挂账核销转账（幂等，重复导入无副作用）
- ✅ 退回 = 挂起待处理（§4.3 闭环）：被退回的账单进发起方「待你处理」卡（显示退回理由），三选一——**改金额重发**（进编辑页，保存后状态回「待伙伴确认」，需再确认）/ **取消 AA**（垫付账单转普通账单）/ **删除**（软删除）；取消与删除生成「已取消」墓碑随同步文件传输，**对方的份额账单自动作废**（§4.6 双方软删除）
- ✅ 分摊口径（§4.4）：两人平分，**奇数总额多出的 1 分归垫付方承担**（按 `payerUid` 判定谁垫付）；升级时自动把历史份额账单重算到新口径（幂等）
- ✅ 统计口径：AA 内部往来（挂账应收）不计入收支统计
- ✅ 图片识别记账：记账页相机入口，拍照/相册选小票或**支付截图** → **本地中文 OCR**（ML Kit，离线运行、图片不出设备）→ **结果面板五要素（金额/日期/备注/账户/分类）全部可修改**（金额手输+候选、日期点选、账户/分类点选更换）→ 采用并填入 → 核对保存；识别引擎为**「平台模板优先（微信/支付宝，锚点+严格校验）、通用规则兜底」的分层架构**，新增平台只需加一个模板类
- ✅ 记账页对标钱迹布局：顶部类型页签 + 5 列分类宫格 + 底部备注/大金额(CNY, 支持+−连算)/属性胶囊(账户·AA·日期) + 计算键盘（长按⌫清空）
- ✅ 防重复记账：保存时检测**同类型 · 同金额 · 同一天**的相似账单，弹窗列出已有账单并要求确认后才入账（防图片识别重复保存、误触双击）
- ✅ **分类自定义**：「我的 → 分类管理」新增/改名/换图标（48 个常用图标库），按 支出/收入/不计收支 分组，长按拖动排序；有账单关联的分类不可删只可改名；记账宫格末尾有「⚙️ 管理」快捷入口
- ✅ 交互优化：账单行**轻滑露出红色删除按钮**，点按钮才删除（可撤销）；AA 开关在记账页胶囊行，实时预览双方份额
- ✅ 数据自愈：启动时自动补建误删/丢失的「AA挂账」账户（AA 账单引用它，缺失会悬空）；历史 AA 份额按新口径自动重算
- ⚠️ 已知限制：进行中的 AA 账单仍锁定直接改删（保证双方一致，须走「退回 → 待你处理」闭环）；尚未导入过伙伴文件时无法发起结算（需先知道对方 uid）；退回理由暂只支持一句话文本

**M3+ 规划**：AA 账单的带同步编辑/删除、云服务器在线同步（数据结构已就绪）、预算、导出 CSV、回收站、多币种


## 代码结构

```
app/lib/
├── main.dart                # 入口、主题、中文本地化
├── theme.dart               # 颜色常量
├── providers.dart           # Riverpod 状态（数据库、选中月份、AA 分摊/结算/配对信息）
├── data/
│   ├── app_database.dart    # drift 表定义（bills/accounts/categories/aa_groups/settlements/meta）
│   └── presets.dart         # 预置分类/账户种子数据 + AA 常量
├── sync/
│   ├── aa_crypto.dart       # 口令派生密钥（PBKDF2）+ AES-256-GCM 文件加解密
│   └── aa_sync_service.dart # 配对 / AA 记账 / 导出导入 / 确认退回 / 结算
├── utils/                   # 金额(分)转换、账户余额计算、日期文案
├── widgets/                 # 数字键盘、月份切换条
└── pages/                   # 明细 / 图表 / 记账 / AA / 账本 / 我的 + 主框架
```

金额一律以 **int 分** 存储，避免浮点误差。

双人使用流程：双方各自配对（同一口令）→ 垫付方记 AA 账单并「导出并发送」（真机走系统分享直发微信/QQ，或「保存到指定位置」存到下载目录）→ 对方**点开 .aas 文件用「AA记账」打开即自动导入**（也可在 AA 页「导入伙伴文件」选择）→ 确认 → 差额到量后任一方「去结算」→ 再次互发同步文件。`.aas` 已注册为系统可识别的打开方式（支持文件管理器、微信聊天文件直接点开）。将来接入云服务器时，只需把文件交换替换为在线收发，数据结构与同步协议不变。

## 变更记录

**2026-10-06 · 交互改进 4/5：金额表达式输入可视化**

- 金额区**原样显示键入内容**：输 65 → 按 + → 输 65 显示「65+65」，不再边输入边跳成求值结果（旧体验 65→71→130，看不出输入值）。
- 计算键盘新增「=」键（底部行变为 `. 0 = 保存`，「再记」改为整行按钮）：**按 = 才求值**，显示结果（65+65= → 130.00）。
- 表达式含运算符但未按 = 直接保存 → 提示「**非法参数**」并阻止保存（不说明详细原因）；纯数字直接保存不受影响。
- AA 分摊预览在表达式输入期间按求值金额实时显示。

**2026-10-06 · 规则约束 3/5：禁止重名资产**

- 账户新增/改名时校验名称唯一：trim 后忽略大小写比较，并把「AA-现金 / AA_现金 / AA·现金 / AA现金」这类 **AA 前缀变体**与「现金」判定为重名（例：AA-现金、AA-银行卡 不允许）；重名时提示「已有同名账户，不允许重名」并阻止保存，编辑保存自身原名不受影响。
- 回归测试：账户重名、AA- 前缀变体重名两条用例（`accounts_page_test.dart`）。

**2026-10-06 · 体验调整 2/5：记账页移除「支出后余额」提示**

- 按需求删除记账页金额下方的「账户支出后/入账后余额」提示行（连同其余额计算逻辑与无用依赖）；转账方向提示与 AA 分摊预览保留。

**2026-10-06 · 稳定性修复 1/5：账户选择弹层底部溢出**

- 记账页、OCR 结果面板、AA 份额入账面板的「选择账户」弹层统一改为**限高（屏幕 60%）+ 内部滚动**，修复账户较多时底部出现 "bottom overflowed by 29 pixels" 黄黑溢出条带的问题。

**2026-10-05 · 退回挂起闭环 + 分摊口径修正**

- **分摊口径修正**：`shareOfNonPayer` 由向上取整改为向下取整——奇数总额多出的 1 分**归垫付方**承担（原实现给了非垫付方，与注释/设计文档 §4.4 相反）。涉及挂账应收、接收方份额账单、差额计算、记账页实时预览；升级后自动重算历史份额账单（垫付方全额账单不受影响）。
- **退回 = 挂起待处理**（设计文档 §4.3 闭环）：
  - 退回可附理由（新字段 `status_note`，随 `.aas` 同步）；
  - 退回(2)/已取消(3) 的分摊组**不计入差额**，「去结算」也不会核销它们；
  - 发起方新增「待你处理」卡：改金额重发（状态回「待伙伴确认」，需再确认）/ 取消 AA（垫付账单转普通账单）/ 删除（软删除）；
  - 取消/删除写入 `status=3` 墓碑并随同步文件传播，对方导入后份额账单自动软删除（§4.6 双方软删除、单写者原则）。
- **数据自愈**：`beforeOpen` 兜底补建丢失的「AA挂账」账户（此前发现设备上该账户被删后 AA 账单引用悬空）。
- **测试**：`app/test/sync/aa_sync_service_test.dart` 更新份额断言与「待入账」流程断言，新增退回理由/挂起不计差额/结算不核销挂起单/取消AA/删除/墓碑同步/历史重算 7 个用例；`app/test/pages/aa_page_test.dart` 适配新 UI（退回理由弹窗、待你处理卡、待入账面板）。
