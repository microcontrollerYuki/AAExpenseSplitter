## 本轮：C-12 共享汇率（2026-10-16）

- 新增“我的 → 汇率设置”，六币种共用 Frankfurter / ECB 每日参考汇率，首次无值 / 过期时联网；可手动覆盖选定币对及反向、恢复网络、刷新及查看来源 / 报价日期 / 获取时间。日参考价不是银行实时成交价；具体端点、精度、缓存和并发规则见 [汇率服务](汇率服务.md)。
- 比例用 BigInt 分数；网络原始十进制不经 double，反向 / 交叉保持精确，最小单位转换只舍入一次。8 秒总超时、32 KiB 响应上限、严格格式 / 完整快照检查；旧缓存、过期、无值及损坏分别提示。手动优先，取消 / 迟到响应不覆盖新状态；缓存写入串行且成功后才发布。
