## 分类迁移与删除规则

- 有效二级右侧提供独立迁移入口，目标必须是同类型另一有效一级。普通名称 / 图标编辑保留父级，迁移专用事务只改变父级与目标同级排序，保留 ID、名称、图标和全部账单引用，追加到目标末尾。
- 目标重名、失效、跨类型、循环、三级或原归属已变时拒绝，并保持窗口和原数据。不能通过普通编辑绕过迁移保护。
- 删除展示将受影响的分类及活跃 / 已删除账单数量，用户选择迁到同类型已有分类、新建分类或未分类；目标可为一级或二级，不能属于被删组。没有账单也须明确确认删除。
- 删除带二级的一级时列出整个组、子级及全部引用数量，必须明确确认整组删除并统一转移账单。用户可取消后先迁出希望保留的二级；不静默级联，不删除账单。
- 转移包含软删除账单，恢复后仍指向有效分类或未分类。新建目标、全部引用转移和分类删除在同一事务；取消不写入，失败、陈旧范围、目标变化或并发新引用整项回滚，不能留下半转移或孤儿引用。
- 仅变更账单本机分类字段，保留原更新时间、金额、账户、日期、备注、AA / 结算关联和同步快照；不突破已结算原始 AA 保护。手续费支出保留唯一转账关联与删除标记；含不可修改关联记录时先校验并说明原因，整项回滚。内部往来和不计收支分类继续沿用原防护。
- 已接入普通账单未分类回显 / 编辑保留。旧账单编辑页拒绝覆盖后台重分类，旧分类窗口不能重建已删除 ID 或覆盖较新状态；返回重开后采用最新归属。
- 此功能是明确分类删除中的受控转移，不扩展任意条件批量修改历史账单，也不进行分类云同步。

## 明细与日历

### 已交付：U-01 年月选择

明细和图表顶部点击年月，打开独立草稿窗口直接选择年 / 月；确认更新为本地月首，保留左右翻月。取消或选择同月保留状态与列表位置，换月返回顶部；跨月不以固定天数推算。未来日历复用控件，日历月份独立于首页明细，不共享筛选状态。

### 已交付：U-02 底部账单详情

点击明细或账户动账，从底部打开共用详情窗口。短内容 / 状态按需收缩，长备注、辅助说明及大字体可滚动；高度最多为扣除键盘后的可用高度 85%，修改 / 关闭入口固定可达。关闭保留原月份和列表位置，修改返回订阅最新内容，再编辑不覆盖旧值；删除后正确显示已删除状态，AA / 结算 / 手续费子账只读限制保持。

R-05 统计明细和 R-08 每日账单将复用该入口，不另开全屏详情。

### 待实现：R-07 月日历聚合

- 沿用 R-01 同一收支账单集合和本地区间，按本地日历日期分组，提供每日收入 / 支出、月收入 / 支出 / 结余以及对应账单 ID 集合。
- 依赖 R-09 / R-10 总览 / 原币模型：总览复用本月同一当前或手动汇率快照及逐笔折算值，原币各自隔离，不直接相加不同原币。展示估算口径、来源与时间，缺率或未知币种明确未纳入 / 待补齐，不把部分结果称完整总额。
- 转账本金、调账、软删除及内部分类收入排除，关联手续费只计一次；真实 AA 支出、普通结算收支及历史内部分类支出沿用既有口径。报表估算不改历史原币或账户实际额。
- 专项覆盖闰年、首末日、跨月零点、上述排除规则、费用计一次、编辑刷新及日 / 月金额守恒；先回归原报表，再交付日历交互。

### 待实现：R-08 日历视图与每日账单

- 图表新增「日历」切换，按月份展示完整日历网格与当月收支结余；复用 U-01 选择年月，日期格分别显示当日收入 / 支出数字，空日不虚构金额。
- 沿用 R-10 总览 / 原币选择与同一汇率快照，缺率 / 过期 / 未纳入状态和月摘要保持一致；图表筛选独立于首页明细。
- 点击日期打开当天账单窗口，提供「全部、收入、支出」筛选。「全部」包含计入该日收支的账单，日历数字、月摘要和窗口复用同一集合及逐笔金额。
- 点账单使用 U-02 底部详情，编辑 / 删除后日历、月摘要与每日窗口同步刷新；关闭保留月份和所选状态。专项覆盖空日、跨月、筛选 / 币种组合、返回保持和修改联动，两台雷电逐日核对合计。

R-10 还须让明细顶部月收入 / 支出 / 结余与图表总览共同默认折合 CNY，各自可切指定原币且状态独立，账单列表继续全币种可见；该能力尚未实现，完整规则以 [多币种与报表计划](下一版本计划-多币种与报表.md) 为准。
