## 分类迁移与删除规则

- 分类管理中，有效二级右侧提供独立迁移按钮，在窗口选择目标一级；普通名称 / 图标编辑继续保留父级。子分类迁移保留其 ID、名称、图标和账单引用，只改变父级及目标同级排序；目标必须是同类型有效一级。同级重名、目标失效、跨类型、循环或三级均拒绝，原归属不变。
- 删除时展示将受影响的分类和账单数量，用户选择迁往已有分类、新建分类或「未分类」。目的分类可以是同类型一级或二级，不能是被删分类组中的节点。没有账单也要明确确认分类删除。
- 删除一级带二级时明确列出整个组、子级数量和所有引用数量，要求确认删除整个组并统一转移账单；用户也可取消后先迁走希望保留的二级。不得静默级联删除，账单本身不得删除。
- 转移包含软删除账单，恢复后仍指向有效分类或未分类。新建目的分类、全部引用转移与分类删除在同一事务内完成；失败、过期目标及并发新引用不能造成部分转移或孤儿账单。
- 只变更账单的本机分类字段，保留原更新时间、金额、账户、日期、备注、AA / 结算关联和历史同步快照；不突破已结算原始 AA 账单保护。含不可修改关联记录时，事务先校验并给出明确处理原因，整项回滚，不能先删分类。内部往来分类继续沿用原防护，不开放跨类型迁移。
- P1-08 已接入普通账单「未分类」编辑保留和旧编辑页分类变化拒绝；用户返回并重新打开后使用最新归属。分类编辑在 DAO 事务内比较原分类快照，避免旧窗口重新创建已删除 ID 或覆盖较新编辑。
- 这是一项明确删除操作中的受控重分类，不提供任意条件批量修改历史账单。普通编辑仍保留禁止直接改归属的保护，迁移使用 P1-06 专用事务；支出 / 收入页面使用 P1-07 / 08 删除转移流程，不计收支仍沿用原防护。

## 明细与日历

- 明细顶部年月可点击；确定后只切换月份，取消不变，不用固定天数计算跨月。图表日历的月份独立于首页明细，复用选择控件而不共用筛选状态。
- 账单详情从底部弹出，按常规详情内容确定高度，上限受可用屏幕约束；长备注、辅助说明及大字体可滚动。关闭回到原列表位置；修改返回显示最新值，删除后显示已删除状态，AA 限制不变。
- 图表新增「日历」切换，按月展示完整网格及当月收入、支出、结余；日期格分别显示当天收 / 支数字，空日不虚构金额。多币种沿用当前所选币种，禁止直接相加。
- 点击日期显示该日账单，提供「全部、收入、支出」按钮。日历数字、月摘要和每日窗口共用同一账单集合，转账、调账、软删除及内部分类收入沿用报表排除规则；真实 AA 支出、普通结算收支及历史内部分类支出继续计入。「全部」包含计入该日收支的账单；详情编辑 / 删除后全部同步刷新。
