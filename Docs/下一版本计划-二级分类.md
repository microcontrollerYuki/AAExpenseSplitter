## 分类管理与选择规则

- 支出和收入都支持「一级 → 二级」，例如「餐饮 / 早餐」「工资 / 兼职」；最多两级，一级本身可直接记账，不强制建立预置二级分类。
- 「我的 → 分类管理」按支出 / 收入分组，一级带二级成组显示；一级旁可新增二级，新增窗口可选所属一级。普通名称 / 图标编辑保留父级；有效二级通过独立迁移窗口改变归属。
- 二级必须属于同类型有效一级，拒绝三级、自循环、跨类型挂接、无效目标和陈旧父级。迁移保留分类 ID、名称、图标与全部账单引用，追加到目标同级末尾；失败保持原归属。
- 名称去除首尾空白后不能为空。同类型、同父级不得重名，不同一级下可有同名二级；新增 / 修改后的名称不得包含路径分隔符 ` / `。旧名称保留，歧义匹配不能取第一条结果。
- 长按手柄排序，一级移动整个组，二级仅在所属一级内移动。排序以「类型 + 父级」为范围，并在事务内完成，不影响其他组。
- 记账和 OCR 共用选择器：一级五列宫格，点击一级直接选中，在所属行下方展开浅灰圆角二级宫格，箭头指向父格；二级可选，再点父格可回到一级。选中二级后父格显示「一级-二级」，完整路径仍可查看。图标始终保留原彩色，通过背景和文字表示选择状态。
- 修改分类或取消选择不清空金额、账户、日期及备注；切换支出 / 收入时重置不适用的分类。旧账单回显实际选中的一级或二级，识别只能确定一级时不猜二级。
- 明细、详情及其他分类展示入口使用完整路径，一级账单显示一级名称；长名称允许省略 / 换行，并提供完整内容。
- 异常旧层级有界解析、只读兜底，不重复展示、不递归失控、不静默修复原数据；不开放新增、拖动或修改异常归属。删除仍须通过数据层校验，不能留下引用。

## 删除、迁移与旧账保护

P1-07 / P1-08 已取代普通支出 / 收入分类原先「有账单就禁止删除」的交互。删除前展示影响范围，用户选择迁到同类型已有分类、新增分类或未分类，再原子删除分类；不删除账单。完整规则见 [分类迁移与删除规则](下一版本计划-分类迁移与明细日历.md#分类迁移与删除规则)。

- 删除带二级的一级分类，必须列出整个组及活跃 / 已删除账单数量，并明确确认整组删除；希望保留某个二级时可取消后先迁出。没有账单也须确认分类删除，不静默级联。
- 目标可以是同类型一级或二级，不能属于被删分类组；新建目标、全部引用转移和分类删除处于同一事务。引用包括软删除账单，恢复后仍指向有效分类或未分类。
- 取消不写入；失败、陈旧范围、目标失效或并发新引用必须整项回滚并提示刷新。旧编辑窗口不能覆盖较新迁移、重建已删除分类 ID 或把账单指回已删除分类。
- 分类字段变更保留账单原更新时间、金额、账户、日期、备注、AA / 结算关联和同步快照。已结算原始 AA、内部往来及其他受保护关联继续校验，不能借重分类绕过保护；手续费支出保留其唯一转账关联。
- `Categories.parentId` 表达层级，`Bills.categoryId` 只存实际选中的分类 ID，不另存一级 ID。旧分类与账单不自动拆分或重分类；普通分类改名不改账单引用，不自动改写 AA 名称快照。

## 统计口径

一级合计包含直属账单和全部二级，每笔只计一次；展开后显示二级与一级直属「未细分」。例如直属 10、早餐 20、晚餐 30，一级合计必须为 60，展开合计也为 60。没有二级时保持一级汇总，缺失分类归入未分类，超过十类不静默丢金额。

当前月统计按原币隔离，收入月摘要与趋势同样不得重复或漏计。内部分类收入排除，真实 AA 支出、普通结算收支及历史内部分类支出保留既有口径；转账本金排除，关联手续费只计一次。收入饼图 R-04、统计账单窗口 R-05、折算总览 R-09 / R-10 尚待实现，规则见 [多币种与报表计划](下一版本计划-多币种与报表.md)。

## AA 分类路径兼容：P1-05 待实现

以下是延后需求，不表示当前已支持唯一完整路径匹配。分类树和本机分类 ID 不随 AA 文件同步；双方分别管理分类。

- 计划沿用 `categoryName` 快照保存显示路径，例如「餐饮 / 早餐」。新客户端仅在本机存在唯一支出完整路径时自动匹配；缺失或歧义进入兜底 / 人工选择，不取首条、不自动创建分类。
- 接收旧文件的单名快照，只在本机支出分类唯一匹配时采用；不同父级同名二级必须回退。
- 旧客户端可展示新路径，但可能无法匹配本机分类；须用旧版 APK 实测金额、份额、确认和结算，文件能导入不能视为分类完全兼容。
- 分类路径不改变结算关联、核销范围、分摊及重导幂等。旧名称含分隔符或存在其他歧义时回退；新旧互导不通过则先调整快照方案再交付。
