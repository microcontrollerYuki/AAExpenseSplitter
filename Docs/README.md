## 当前可以做什么

| 模块 | 已交付功能 | 当前边界 |
|---|---|---|
| 手动记账 | 支出 / 收入 / 本人钱包转账，金额运算键盘、日期时间、备注、连续记账、同币种 / 同类型 / 同金额 / 同自然日相似提醒 | 相似提醒需要用户判断，尚无可靠交易来源幂等 |
| 分类 | 支出 / 收入最多两级；先选一级、二级可选；五列宫格、所属行下展开二级，图标保持原彩色；新增、编辑、同级排序 | AA 完整分类路径匹配仍待 P1-05 |
| 分类维护 | 子分类迁往同类型另一一级；删除时将账单转到已有 / 新增 / 未分类，整组删除明确确认，包含软删除引用 | 受保护 AA / 结算等关联仍执行事务保护，不是任意批量重分类 |
| 明细 | 月份左右切换及手选年月、自定义日期范围、按日分组、默认折合 CNY 收支结余及独立原币切换、底部详情窗口、修改刷新、滑删与撤销 | 尚无搜索或多条件组合检索、回收站界面 |
| 多币种记账 | CNY、USD、HKD、EUR、JPY、GBP；金额后直接点币种；跨币账户实际扣 / 入账金额需确认；OCR 结果可选币种 | 切币种不自动换算；JPY 为整数；未知或含糊币种不擅自推断 |
| 转账及手续费 | 同币等额、跨币双金额，账户 / 本金变化后重确认；跨币转账按共享汇率预填入账候选，可手动改率或实际额；转账内填写、分类、修改和取消手续费，显示总扣款，关联删除 / 撤销 | 费用按来源账户币种额外扣款，只能随所属转账维护；候选需显式采用，设备级断网场景未验收 |
| 共享汇率 | 我的 → 汇率设置；六币种联网每日参考价、手动双向覆盖 / 恢复、精确比例、来源时间、缓存与离线提示；跨币转账预填已接入 | 不是银行实时成交价；R-09 折算模型与 R-10 明细 / 图表默认总收支已接入，保存汇率不改历史账单 |
| 账户与资产 | 六币种账户、期初额、实际余额、动账明细、分币种净资产，引用账户的币种 / 删除保护 | 不同币种资产分别列出，尚未折算统一总资产 |
| 图表 | 月 / 年 / 自定义范围、收入 / 支出饼图与完整排行、一级 / 二级与直属展开、图项账单窗口与编辑刷新、总览 / 原币组合及趋势金额守恒；R-07日历聚合模型 | R-07已推送核对，R-08日历界面和订阅未实现；长范围趋势轴限制见下方 |
| 双人 AA | 口令配对、平分、确认 / 退回 / 重发 / 取消、差额与逐条结算、加密 `.aas` 文件导入导出、重复导入保护 | 仅 CNY；伙伴确认先跟踪应付，结算后逐条落收支；需要人工交换文件，无在线自动同步 |
| 图片 OCR | 相机 / 相册、本地中文 ML Kit、微信 / 支付宝图片模板、可修改的金额 / 日期 / 备注 / 账户 / 分类结果 | “采用”回填表单，仍需用户保存；不等同无障碍识屏、支付成功判断或自动入账 |
| 数据与升级 | Drift / SQLite 本地六表、schema 6、安全迁移与软删除；整数最小单位与 BigInt 聚合 | R-06 双雷电与完整原六表核对通过；目标真机 / iOS / 正式发布未验收 |
