### 2026-10-08 测试基线修复

## 四、已知问题与运行备忘

1. **testWidgets 里跑真实异步会永久挂起**：文件读取、PBKDF2 等真实异步在假时钟区里不会自行完成，需包 `tester.runAsync(...)`（导入/导出用例已按此处理）
2. **中断测试会留孤儿进程**：`flutter test` 被强杀后残留的 `flutter_tester` 会映射 `build/native_assets/windows/sqlite3.dll`，导致下次运行报 "Flutter failed to delete file ... sqlite3.dll"。解法：`Stop-Process` 杀掉 `flutter_tester/dart` 进程后手动删除该 DLL，或 `flutter clean`
3. **不要并行跑两个 flutter 命令**（同一工程）：会互相抢 native_assets 构建产物
4. 「结算：确认后核销」曾出现渲染层挂起（与页面重构中间态有关），如复现优先检查该用例
