## 命令与耗时控制

从当前检出的 `app` 目录运行，不固定切到另一份工作区：

```powershell
# 全量短回归；单测试默认 20 秒上限
flutter test --no-pub --reporter expanded --timeout 20s

# C-12 最终专项：五个新增文件与既有入口回归
flutter test --no-pub --reporter expanded --timeout 20s test/exchange/exchange_rate_test.dart test/exchange/exchange_rate_service_test.dart test/exchange/exchange_rate_source_test.dart test/exchange/exchange_rate_database_test.dart test/pages/exchange_rates_page_test.dart test/pages/mine_page_test.dart

flutter analyze --no-pub
flutter build apk --debug --no-pub
adb -s emulator-5554 install -r build/app/outputs/flutter-apk/app-debug.apk
adb -s emulator-5556 install -r build/app/outputs/flutter-apk/app-debug.apk
```

此电脑 SDK 在 `D:\Dev`；使用本机脚本可保持临时文件、Pub / Gradle 缓存及构建产物集中在 D 盘。脚本配置的目标工作区应为本次检出：

```powershell
& 'D:\Projects\AAExpenseSplitter\.local-dev\aa-dev.ps1' -Tool flutter -ToolArgs @('test','--no-pub','--reporter','expanded','--timeout','20s')
& 'D:\Projects\AAExpenseSplitter\.local-dev\aa-dev.ps1' -Tool flutter -ToolArgs @('build','apk','--debug','--no-pub')
```

同一工程 Flutter / Dart 命令顺序执行，避免 native assets 构建竞争。全量 runner 优先控制在约 60 秒，分别记录测试本身和启动 / 构建总耗时；首次依赖下载单独记录。超时 / 失败先定位，不无限等待或反复重跑掩盖问题。异步 Widget 测试区分真实 I/O 的 `runAsync` 与测试时钟，避免事务释放前读同库及 Snackbar 清理竞态。

## 每个小点的交付门槛

1. 选定一个 TODO ID、明确行为与正反例，完成实现后自查并重新审查关联数据、失败回滚和旧账；记录独立复查结果。
2. 跑受影响专项及全量短回归；数据库变化增加真实文件迁移 / 回滚，Android 服务变化增加原生与安装验证。新分析问题本轮处理，存量单列。
3. 构建并覆盖安装两台既有雷电，保留用户数据；实际操作新功能与“记账 → 修改 → 明细 / 图表 / 账户”冒烟。AA 相关点增加双机文件交换，真实平台点须用真实目标版本验收。
4. 测试前后核对数据。需要造账时使用明确 QA 标识，清理只按已确认 ID；比较完整业务表与关联，保留账户、分类、旧账、AA 和结算。不得清空应用数据代替回滚。
5. 记录实际测试数量 / 耗时、设备 / 操作与限制；仅推送代码、测试、文档。远端提交核对成功后，才将该编号标为完成。

文档小点另检查：65 个编号与状态不变、已完成 / 待实现不混淆、本地链接有效、历史档案边界清楚、`git diff --check` 通过。复跑回归并核对当前 APK 安装 / 冒烟，记录实际结果；文档未改应用时不声称交付新功能。

设备数据库、原始支付文本、真实交易号、`.aas` 文件、截图、日志和 QA 脚本只留本机 D 盘，不提交仓库。签名 / 正式发布的最终验收仍按 P7 执行。

C-12 断网验收中，雷电关闭 WiFi 会连带断开 ADB；通过界面恢复后，实例 0 改用宿主网络控制验证超时和缓存，实例 1 已在断开 WiFi 状态实际验证网络不可用和缓存。两台之后均恢复联网刷新及原 WiFi / 移动数据 / 飞行模式设置。后续不要依赖关闭控制链路后仍可用 ADB 恢复。缓存清理只针对测试前不存在的 `exchange_rates.v1`，执行前核对完整原行 / 字段和精确缓存值，首错退出并回滚；执行后完整六表与原始指纹一致。
