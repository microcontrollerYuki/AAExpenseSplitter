2. 跑受影响专项及全量短回归；数据库变化增加真实文件迁移 / 回滚，Android 服务变化增加原生与安装验证。新分析问题本轮处理，存量单列。
3. 构建并覆盖安装两台既有雷电，保留用户数据；实际操作新功能与“记账 → 修改 → 明细 / 图表 / 账户”冒烟。AA 相关点增加双机文件交换，真实平台点须用真实目标版本验收。
4. 测试前后核对数据。需要造账时使用明确 QA 标识，清理只按已确认 ID；比较完整业务表与关联，保留账户、分类、旧账、AA 和结算。不得清空应用数据代替回滚。
5. 记录实际测试数量 / 耗时、设备 / 操作与限制；仅推送代码、测试、文档。远端提交核对成功后，才将该编号标为完成。

文档小点另检查：唯一编号/状态、本地链接、历史边界与`git diff --check`。当前70个唯一ID，原65项保留，新增五项仍待办；R-08全部门槛及远端核对通过后仅新增其勾选，38完成/32待办。推送后相关短回归15/15通过，完成状态另作文档提交；不虚构新功能或未完成的验证。

设备数据库、原始支付文本、真实交易号、`.aas` 文件、截图、日志和 QA 脚本只留本机 D 盘，不提交仓库。签名 / 正式发布的最终验收仍按 P7 执行。
